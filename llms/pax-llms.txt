# Pax

> Pax (Pax AI) is a San Francisco-based AI company that automates U.S. duty drawback claims — helping importers, retailers, and manufacturers reclaim overpaid tariffs and import duties. It positions itself as the "AI Broker for Tariff Refunds" / "TurboTax for import duty rebate," automating data extraction, transaction matching, refund calculation, and electronic claim submission to U.S. Customs and Border Protection.

This is an API Evangelist network profile. At enrichment time Pax exposes a live but locked-down JSON API host and no public OpenAPI, reference documentation, SDKs, or developer program.
